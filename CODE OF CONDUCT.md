# Code of Conduct

T.R.A.G.I.C. is a small open-source project. The goal is to keep collaboration straightforward and respectful for everyone who shows up to use it, report a bug, or contribute code.

## The short version

- Be respectful. Disagree about code, not about people.
- No harassment, personal attacks, or discriminatory language in issues, PRs, or discussions.
- Assume good faith. Most bug reports and bad PRs come from people trying to help, not people trying to waste your time.
- Keep discussions on-topic and focused on the project.

## Scope

This applies to all project spaces — GitHub issues, pull requests, discussions, and any other official communication channels for this repo.

## Reporting an issue

If someone's behavior violates this, open an issue tagged `conduct` or contact the maintainer directly through GitHub. Reports will be handled privately and as fairly as possible.

## Enforcement

The maintainer may edit, lock, or remove comments/issues/PRs that violate this Code of Conduct, and may block repeat offenders from the repository. This is a judgment call made on a case-by-case basis, not a strict three-strikes system.

---

This is a lightweight policy for a small project — not a substitute for the [Contributor Covenant](https://www.contributor-covenant.org/), which this is loosely based on.
